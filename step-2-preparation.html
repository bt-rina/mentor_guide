Step 2

사전 준비사항

멘토님으로 합류하신 후 최초 1회만 설정하면 되는 녹화 환경 세팅입니다. 이후 매주 멘토링 시간에 OBS가 자동으로 켜져 녹화하고, 종료되면 드라이브에 자동으로 업로드됩니다.

SETUP 개강 전주 수요일 전까지 · ⏰ 약 20분

멘토링 녹화 준비

녹화본은 수강생의 복습 자료로 제공됩니다. OBS와 구글 드라이브를 연동해 자동 녹화 · 자동 업로드 환경을 세팅해 주세요.
세팅을 마치면 STEP 3의 MISSION 1에서 실제로 동작하는지 테스트합니다.

💬 디스코드
  • 수강생과 실시간으로 수업하는 곳
🎥 OBS
  • 그 수업 화면을 녹화해 파일로 저장하는 곳
  • '방송 시작'이 아닌, '녹화 시작'을 사용하세요.

1단계 · OBS Studio 설치

🖥 Windows
  • obsproject.com/download 접속 후 Windows 버전 다운로드 및 설치
  • 설치 중 '최적화 마법사'가 나오면 취소 (전용 커스텀 프로파일 설정 예정)
🍎 Mac
  • obsproject.com/download 접속 후 macOS 버전 다운로드, Applications 폴더에 드래그
  • 첫 실행 시 아래 4가지 권한 필수 허용 (시스템 설정 > 개인정보 보호 및 보안)
    • 화면 및 시스템 오디오 녹음 > OBS 체크
    • 마이크 > OBS 체크
    • 입력 모니터링 > OBS 체크
    • 손쉬운 사용 > OBS 체크

2단계 · OBS 프로파일 가져오기

⬇ OBS_profile.zip 다운로드
  • 다운로드한 'OBS_profile.zip'의 압축을 해제하여 'OBS_profile' 폴더를 준비합니다.
    • Windows에서 압축 해제가 되지 않는 경우 반디집(Bandizip)을 설치 후 시도해 주세요.
  • OBS 상단 메뉴 > 프로파일(Profile) > 가져오기(Import)
  • 압축 해제한 'OBS_profile' 폴더 선택 > 열기
  • OBS 프로파일 메뉴 재선택 > '블루타이거 멘토링' 선택
💡 위 설정으로 1080p/30fps, 고품질 녹화가 모두 설정됩니다.

3단계 · Google Drive 데스크톱 앱 설치

  • google.com/drive/download 접속 후 데스크톱용 Drive 설치
  • 설치 후 구글 계정으로 로그인
  • 로그인 후 드라이브 앱 좌측 상단 'Drive 폴더 열기' 버튼 클릭 후, 아래 경로에 따라 멘토님 폴더를 확인합니다.
    • Mac: /Volumes/GoogleDrive/공유드라이브/[bluetiger] 멘토링 녹화본/성함
    • Windows: GoogleDrive:\공유드라이브\[bluetiger] 멘토링 녹화본\성함
⚠️ 공유 드라이브 확인 불가 시 운영팀에 문의해 주세요. (드라이브 웹으로 접속하기)

4단계 · OBS 녹화 경로 변경

  • OBS 하단 제어 패널의 '설정(Settings)' 버튼 클릭
  • 출력(Output) 탭 > '녹화 저장 경로(Recording Path)' 항목 찾기
  • '찾아보기(Browse)' 클릭 후 공유 드라이브 내 나의 저장 폴더로 이동
    • Mac: Google Drive > Shared drives > 드라이브이름 > 성함으로 된 폴더
    • Windows: G:\Shared drives\드라이브이름\성함으로 된 폴더
  • 해당 폴더로 경로 적용 후 '확인(OK)' 클릭
💡 이 경로 설정이 자동 업로드의 핵심입니다. 녹화본이 드라이브 폴더에 바로 저장되면서, 구글 드라이브 앱이 이를 자동으로 업로드합니다.

5단계 · 화면 캡처 소스 추가

  • OBS '소스 목록(Sources)' 패널 하단의 더하기 버튼(+) 클릭 > 화면 캡처(디스플레이 캡처) 선택
  • 디스플레이 캡처 > 디스코드가 표시될 디스플레이 선택
  • OBS 하단 오디오 믹서에서 동작 확인
    • '데스크톱 오디오' : 디스코드 소리 재생 시 초록색 바가 움직이면 완료
    • '마이크' : 말할 때 초록색 바가 움직이면 완료
💡 캡처 화면이 잘리거나 크기가 맞지 않는 경우:
소스 우클릭 > 변환 > '화면에 맞추기'를 선택하면 전체 화면 크기에 맞게 조정됩니다.

6단계 · 오디오 세팅 (목소리 누락 방지)

① 마이크 장치 지정
  • OBS 오디오 믹서의 '마이크/Aux' 텍스트 클릭 > 속성 > 장치
  • '기본 장치' 대신 실제 사용하는 마이크를 직접 지정합니다.
    • '기본 장치'는 엉뚱한 장치를 잡아 소리가 아예 들어오지 않을 수 있습니다.
    • 여기서 지정한 마이크는 디스코드에서 쓰는 마이크와 같아야 합니다.
② 오디오 모니터링 끄기
  • 오디오 믹서 하단 'Options' > 오디오 고급 설정 > '오디오 모니터링'
  • 마이크/Aux와 데스크톱 오디오 둘 다 '모니터링 끔'으로 설정합니다.
이럴 땐 이렇게
  • 녹화본에 내 목소리가 안 담긴 경우 : 마이크 장치를 직접 지정하고, 모니터링을 '끔'으로 설정
  • 소리가 울리는 경우(에코) : 모니터링을 '끔'으로 설정

멘토링 시간에 맞춰 OBS가 자동으로 켜지고 녹화를 시작하도록 설정합니다.

사용하시는 운영체제의 카드만 펼쳐서 따라가시면 됩니다. (접속하신 기기에 맞는 카드가 자동으로 펼쳐집니다)

🖥 7단계 · 자동 실행·녹화 설정 (Windows) 작업 스케줄러로 예약합니다

+
7-1. OBS 설치 경로 확인
  • 바탕화면 또는 시작 메뉴에서 OBS 아이콘을 우클릭 > '파일 위치 열기' 클릭
  • 열린 폴더에서 obs64.exe 우클릭 > '속성' > '일반' 탭에서 '위치' 경로를 메모합니다.
    • 일반적인 기본 경로: C:\Program Files\obs-studio\bin\64bit\obs64.exe
⚠️ 경로가 C:\ProgramData\Microsoft\Windows\Start Menu\Programs 처럼 보이면, obs64.exe를 다시 우클릭하고 '파일 위치 열기'를 한 번 더 실행하세요.
7-2. 작업 스케줄러 열기
  • Windows 키 + S를 눌러 검색창에 '작업 스케줄러'를 입력하고 클릭합니다.
7-3. 새 작업 만들기
  • 오른쪽 패널에서 '기본 작업 만들기'를 클릭합니다.
  • 이름 입력 예시: 'OBS 자동 실행' → 다음으로 이동
  • 트리거 선택: '매주' 선택하고 다음으로 이동
  • 아래 항목을 설정합니다:
    • 시작 날짜: 오늘 날짜로 설정
    • 실행 시간: 멘토링 수업 10분 전 (예: 멘토링 오후 9시 → 실행 시간 20:50)
    • 요일 선택: 본인 강의 요일 체크 (예: 월요일)
  • 동작 선택: '프로그램 시작'을 선택하고 다음으로 이동
  • '찾아보기'를 클릭하여 7-1 단계에서 메모한 obs64.exe 경로를 선택합니다.
  • '인수 추가(선택)' 칸에 아래를 입력합니다(자동 녹화 시작 + 트레이 최소화):
--startrecording --minimize-to-tray --disable-shutdown-check
  • '시작 위치(옵션)' 칸에 아래를 입력합니다:
C:\Program Files\obs-studio\bin\64bit
  • '마침'을 클릭하면 완료됩니다.
⚠️ PC가 잠금 상태이거나 절전 모드이면 자동 실행이 되지 않을 수 있습니다.
멘토링 전날 PC 전원이 켜진 상태로 유지해 주세요.
🎯 설정을 마치셨다면, STEP 3 · MISSION 1에서 예약 시간을 잠시 바꿔 전체 흐름을 테스트합니다.

🍎 7단계 · 자동 실행·녹화 설정 (macOS) 터미널의 crontab으로 예약합니다

+
7-1. 터미널 열기
  • Command(⌘) + Space로 Spotlight를 열고, '터미널' 입력 후 Enter를 누릅니다.
7-2. crontab 설정
  • 터미널에 아래 명령어를 입력하고 Enter를 누릅니다:
crontab -e
  • i키를 눌러 입력 모드(INSERT)로 전환 후, 아래 형식으로 입력합니다:
    • 50=분, 20=시간(오후 8시), 1=요일(월1, 화2, 토6, 일7)
50 20 * * 1 open -a OBS --args --startrecording
💡 두 개 과정을 담당하시는 경우, 요일을 쉼표로 구분하여 한 줄에 입력합니다.
[예시: 월요일 + 화요일] 50 20 * * 1,2 open -a OBS --args --startrecording
  • Esc를 누르고 :wq를 입력한 후 Enter 키를 누릅니다(저장 후 종료).
  • 저장된 내용은 crontab -l 로 언제든 확인할 수 있습니다.
7-3. 권한 허용
  • 이미지에 해당하는 팝업이 표시되면 '허용'을 눌러, 터미널이 OBS를 제어하도록 허용합니다.
⚠️ 맥이 잠금 상태나 절전 모드이면 crontab이 실행되지 않을 수 있습니다.
시스템 설정 > 배터리에서 '자동으로 잠자기' 시간을 멘토링 시간 이후로 조정해 주세요.
🎯 설정을 마치셨다면, STEP 3 · MISSION 1에서 예약 시간을 잠시 바꿔 전체 흐름을 테스트합니다.

녹화 방법 (세팅 완료 후)

  • 7단계 자동 실행 설정을 완료하셨다면, 멘토링 시작 전 OBS가 자동으로 켜지고 녹화가 자동으로 시작됩니다. OBS 하단의 녹화 카운터를 확인해 주세요.
  • 멘토링 종료 후 '녹화 중단' 버튼 또는 F9 키를 눌러(Mac: fn + F9) 녹화를 종료합니다.
  • 녹화본은 공유 드라이브의 멘토님 전용 폴더에 자동으로 업로드됩니다.
⚠️ 업로드 완료 전에 PC를 종료하면 업로드가 중단될 수 있습니다.
Google Drive 앱이 백그라운드에서 자동 업로드하므로 PC를 사용하면서 기다리셔도 됩니다.

녹화본 파일 관리

  • 파일명은 녹화 시작 시점 기준으로 설정됩니다.
  • 여러 클래스를 담당하시는 경우, 클래스별 하위 폴더를 만들어 구분해 주세요.
  • 드라이브 웹 링크에 영상이 보이지 않는 경우, 드라이브 앱에서 동기화 상태를 확인해 주세요. 앱에서 동기화가 완료되면 웹에서도 확인할 수 있습니다.
  • 영상 링크 공유가 필요하실 경우, 드라이브 전체 링크가 아닌 멘토님 전용 폴더 링크를 공유해 주세요.
  • 녹화본은 개인정보 유출 방지를 위해 종강일+7일 후 삭제됩니다.
🎥 멘토링 녹화는 매주 빠짐없이 진행해 주세요. 녹화가 누락될 경우 별도 보강 영상 녹화 또는 서면 자료 제작을 요청드릴 수 있습니다.

자동 실행·녹화 끄는 방법 일시 중지하거나 시간을 바꿀 때 확인합니다

+
🖥 Windows
  • 작업 스케줄러 열기 (Windows 키 + S → '작업 스케줄러' 검색)
  • 왼쪽 패널 '작업 스케줄러 라이브러리'에서 설정한 작업을 우클릭
  • '사용 안 함' → 일시 중지 / '삭제' → 완전 제거
  • 시간만 바꾸려면: 해당 작업 더블클릭 → '트리거' 탭 → 편집 → 시간·요일 수정
💡 '사용 안 함'은 나중에 다시 '사용'으로 되돌릴 수 있습니다. 완전히 지우고 싶을 때만 '삭제'를 선택하세요.
🍎 macOS
  • 터미널에서 crontab -e 입력 후 i로 입력 모드 전환
  • OBS 관련 줄 처리
    • 1. 일시 중지: 줄 맨 앞에 "#" 추가
      # 50 20 * * 1 open -a OBS --args --startrecording
    • 2. 완전 삭제: 해당 줄 전체 삭제
    • 3. 시간 변경: 맨 앞의 '분 시 * * 요일' 숫자만 수정
  • Esc 후 :wq를 입력하고 Enter로 저장
💡 # 을 붙이면 설정은 그대로 남은 채 비활성화됩니다. 다시 활성화하고 싶을 때 # 만 지우면 됩니다.
